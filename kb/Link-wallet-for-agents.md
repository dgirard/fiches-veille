# Link wallet for agents

> **Type** : TECHNOLOGIE | 11 relations | 1 fiches sources

## Attributs

- **définition** : Portefeuille Stripe lancé le 29 avril 2026 donnant à un agent un accès programmatique à Link par OAuth : sur demande de dépense approuvée par l'humain, l'agent reçoit une carte à usage unique ou un Shared Payment Token adossé aux moyens de paiement déjà enregistrés, sans jamais accéder aux identifiants bruts
- **statut** : Livré au 29 avril 2026 (CLI, applications iOS et Android) ; les limites de dépense, l'action sans approbation supplémentaire, les agentic tokens et les stablecoins sont annoncés au futur
